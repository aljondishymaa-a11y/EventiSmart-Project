# منصة المؤتمرات الذكية - سوريا (Smart Conference Platform)

منصة إلكترونية متكاملة مصممة لإدارة وتنظيم المؤتمرات العلمية والتقنية في سوريا. تهدف المنصة إلى تسهيل عملية التواصل بين المنظمين، المتحدثين، والمشاركين، وتوفير أدوات رقابية وإحصائية لمدير النظام.

## 🚀 المميزات الأساسية
* **نظام أدوار متكامل**: تدعم المنصة أدواراً محددة تشمل (مدير النظام، منظم المؤتمر، متحدث، ومشارك).
* **إدارة المؤتمرات**: إمكانية إنشاء المؤتمرات، تحديد المواقع الجغرافية (المدن السورية)، وإدارة طاقة الاستيعاب.
* **لوحة تحكم ذكية**: توفر إحصائيات شاملة مدعومة برسوم بيانية (Chart.js) لمتابعة نمو المنصة ومعدلات الحضور.
* **نظام تقارير متقدم**: إمكانية تصدير بيانات المستخدمين والمؤتمرات والتقييمات إلى ملفات Excel.
* **إدارة الطلبات**: نظام لمراجعة وقبول أو رفض طلبات إنشاء المؤتمرات من قبل الإدارة.
* **تقييم وحضور**: تتبع تسجيل الحضور الفعلي ونظام تقييم للمؤتمرات المنتهية.

## 🛠 التقنيات المستخدمة
* **الإطار البرمجي**: Django 5.2.5 (Python).
* **قاعدة البيانات**: SQLite (لبيئة التطوير).
* **الواجهة الأمامية**: Bootstrap 5 (RTL Support) و Font Awesome.
* **الرسوم البيانية**: Chart.js.
* **معالجة البيانات**: Pandas و Openpyxl لتصدير التقارير.

## 📂 هيكلية المشروع
* `smart_conference/`: المجلد الرئيسي للإعدادات وروابط URL الأساسية.
* `conference/`: التطبيق الأساسي الذي يحتوي على النماذج (Models) والعروض (Views).
* `templates/`: قوالب HTML المصممة بواجهات متجاوبة.
* `static/`: الملفات الثابتة (CSS, JS).
* `seed_database.py`: ملف برمجي لتعبئة قاعدة البيانات ببيانات اختبارية.

## 🔧 طريقة التشغيل
1.  **تثبيت المتطلبات**:
    ```bash
    pip install -r requirements.txt
    ```
2.  **تنفيذ الهجرات (Migrations)**:
    ```bash
    python manage.py makemigrations
    python manage.py migrate
    ```
3.  **تشغيل الخادم**:
    ```bash
    python manage.py runserver
    ```
